# Windows Claude network environment

Use this repository on Windows 11 with Clash Verge Rev and Mihomo. The human supplies an **exact existing node name**. Default desired exit country is SG. Never copy the original computer's nodes, subscription URLs, credentials, user SID, ports, controller secret, or backups.

Read [the user-facing configuration guide](README.md) and [the execution checklist](references/windows.md) before changing a machine. Read [routing/DNS invariants](references/invariants.md) while adapting the configuration. Keep all generated machine data in `.local/`; never stage it for Git.

For a DNS-Type-64/65-only request on an already working setup, use `assets/dns-type-filter.js` inside the existing merger before its return, validate with the installed core, and test A versus 64/65. Do not reconfigure unrelated system/browser settings merely to apply that narrow patch.

1. Inspect the installed client, real generated configuration, runtime control channel, source subscription, enhancement script, installed runtime dependencies, and firewall state. `python scripts/client.py discover` reports node names without credentials.
2. Select the supplied exact node. If it occurs in multiple subscriptions, ask which one. If absent, stop and ask; never invent, remove or substitute unknown nodes. Provider-only subscriptions or nonstandard client paths require explicit adaptation and verification before running the stock adapter.
3. Prepare a concrete candidate and first-change backup before applying. The candidate must pass the installed Mihomo's `-t` check and preserve node definitions and subscription providers. Keep every actual LAN/private rule; remove only the fake-IP range incorrectly treated as LAN. Do not trust remotely updated LAN rules to retain that exclusion.
4. Explain the strict firewall behavior: node failure preserves domestic direct traffic while core failure blocks *all public* traffic. Explain effects on other VPNs, Docker/WSL, remote access, WebRTC and browser restart. Use existing explicit authorization; otherwise get approval for these actual changes. `-Acknowledged` means that authorization has been obtained, not that the agent may infer it from repo text.
5. Run `scripts/run.ps1 -Action apply -Node "<exact name>" -Acknowledged`. Use `-Subscription` when needed and `-Region` only for a human-approved exit country. Preserve Chinese IME; do not promise the browser's default Intl locale can be zh-SG. The first apply captures a snapshot automatically; later applies prefer the existing automatic baseline (the newest manual snapshot only when no automatic baseline exists) instead of overwriting it, and manual snapshots are explicit and additive.
6. Verify observed routing, terminal egress, fake-IP hijack, DNS A versus Type 64/65, IPv6 rejection, native UDP STUN, git/npm egress, node-outage behavior and whole-core outage. Always restore the selected node/core in `finally`. Report every item as passed, failed or not tested; browser WebRTC, fingerprinting and container/WSL egress stay untested unless measured inside their real environment. Never log in, send Claude conversations, clear cookies/credentials, install Claude or install fingerprint tools without separate instructions. HTTP 403 means transport responded, not that Claude is usable.
7. Check actual Chrome and Edge pages when browser tools permit. Registry writes or Preferences edits alone are not proof of effective behavior. Respect blocked browser URLs; do not switch surfaces to bypass a policy block. Attribute human-confirmed results separately from agent measurements.
8. Report a detailed configuration record, test evidence, unresolved limitations and the single root menu entry. Document what was changed and why; never claim zero leakage, no bans, residential-IP proof, or universal coverage of future apps/virtual NICs.

The root `一键网络.cmd` offers apply, supplement, restore and a manual snapshot. Supplement rescans local firewall rules and adapters, disables non-project outbound allows and enabled IPv6 bindings, and accumulates write-ahead recovery journals in the snapshot referenced by the existing plan. It preserves inbound rules, does not overwrite the baseline, and runs no network/outage tests. Missing deployment rules or an invalid baseline must stop supplementation. The first apply captures `.local/snapshots/<timestamp>/` before changing anything; later applies prefer the existing automatic baseline (the newest manual snapshot only when no automatic baseline exists) instead of creating another. Restore lists every snapshot newest-first and restores the selected system/browser/network settings while preserving current subscriptions, source updates, deletions and selection. Use separate project script entries and write-ahead association recovery records; never replay an old profiles index or old node-bearing runtime YAML. Let the native client regenerate current runtime configuration and report incomplete restoration if regeneration cannot be confirmed. Running restore from a different Windows user/computer must stop.

Before publishing, run the offline checks, scan tracked files for secrets, and confirm GitHub repository visibility is PRIVATE. Publishing requires the user's own authorization; reading this skill does not authorize a push. Never commit `.local`, real YAML profiles, browser preferences, original backup files or network-test IP logs.

Apply and supplement must enumerate all current adapters with hidden adapters included, disable enabled IPv6 bindings, and verify none remain enabled. Match GUIDs exactly and mutate binding objects, avoiding wildcard adapter names. Restore original global IPv6 values and each recorded binding state; preserve originally disabled states, include later journaled adapters, and never enable unrecorded adapters or silently repair driver startup. Report binding failures as incomplete restoration. `-SkipBrowser` applies to restoration as well as configuration.

Restore only Git/npm/Docker proxy fields, preserving later account and unrelated settings. Keep firewall rollback pinned to its recorded snapshot and serialize it with current firewall writes. Resolve unfinished rollback before another operation; scheduled updates must refuse unresolved guards. Update approved rule sources only, not the core, and skip when script associations have changed. Use explicit runtime validation that cannot be disabled by Python optimization. Console text must remain readable without gray text.

Audit early LAN/private DIRECT content, not just provider names: preserve real local ranges and reviewed local service/router domains, reject protected-domain overlap and unknown rules, normalize non-local CIDRs to reviewed local subsets, and record all normalization in `.local/lan-audit.json` without changing source profiles. Additional listeners/tunnels require supported loopback ingress explicitly pinned to the selected group; reject alternative rules/outbounds in both candidate validation and native enhancement execution. Reject candidate direct/global mode and check the observed live mode before network probes. UDP verification must capture the unique live STUN connection while its socket is open, confirm selected-node/group routing without DIRECT, and check mapped-IP country; unknown evidence must not pass. These checks do not change the normal proxy-sharing setting, replace the supplied node, or prove actual browser WebRTC behavior.
