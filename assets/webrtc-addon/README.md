# 本地 WebRTC 保护 1.0.0

这是本项目随附的 MIT 许可扩展源码，不是商店的 WebRTC Control。
无下载地址、远程代码、统计或账号功能；Chrome、Edge 共用同一份文件。

配置会校验并准备 `.local/webrtc-addon/1.0.0`。在标准浏览器中首次使用时：

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 启用“开发者模式”，选择“加载已解压的扩展”，选取软件显示的本地目录。
3. 确认“本地 WebRTC 保护”已启用，刷新此前打开的网页。

每份浏览器资料需各加载一次，后续配置复用原目录，无需联网下载。
不要删除或移动加载目录。版本变化后需重新加载/选择软件显示的新目录。
隐私窗口需另行允许，浏览器内部页、受限页面、扩展页面及 Worker 等环境不保证覆盖。
可能影响网页语音、视频和点对点连接；Firefox 使用原生禁用策略，不需该扩展。
现有商店版保持原状；旧版强制安装策略可能继续触发浏览器自己的安装或更新。
普通非域管理 Windows 不支持从本地包静默安装进已有资料，软件不会修改浏览器资料来绕过此限制。
安装、启用及本地文件记录不代表实际阻断通过；真实浏览器行为未验证。
